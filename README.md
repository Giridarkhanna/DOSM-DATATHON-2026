# TourAI: Beyond The Famous 🌏

**DOSM Datathon 2026 | Team: Statistically Unbothered**

## Project Overview
TourAI is a data-driven tourism intelligence project that uses Machine Learning and Explainable AI to forecast tourism demand and identify hidden tourism opportunities across Malaysia.

The project aims to support sustainable tourism development through predictive analytics and interactive visualizations.

## Objectives
- Analyze tourism trends across Malaysian states.
- Forecast tourism demand for 2025–2026 using XGBoost.
- Identify key factors influencing tourism demand using SHAP.
- Discover emerging tourism destinations through data analysis.

## Tools & Technologies
- **Machine Learning:** XGBoost
- **Explainable AI:** SHAP
- **Data Visualization:** Power BI
- **Data Sources:** DOSM Open Data, economic and geospatial datasets

## Methodology
1. Data collection and preprocessing
2. Exploratory data analysis and feature engineering
3. Tourism demand forecasting using XGBoost
4. Model interpretation using SHAP
5. Interactive Power BI dashboard development

## Key Results
- Achieved an **R² score of 0.8474** for tourism demand forecasting.
- Identified **5 potential hidden gem states**.
- Developed a four-page interactive Power BI dashboard for tourism insights and forecasting.
